# Modulo Analiticas

## Descripcion del modulo
Este modulo esta reservado para metricas y analisis del comportamiento del sistema.
La idea es resolver reportes de rendimiento, tiempos y trazabilidad de ejecucion.

## Responsabilidades
- Calcular KPIs por politica, departamento y usuario.
- Generar reportes historicos.
- Exponer informacion para tableros de control.

## Clases principales
### Controllers
- Aun no hay controllers implementados.

### Services
- Aun no hay services implementados.

### Models
- Aun no hay modelos implementados.

## Endpoints
Este modulo no expone endpoints HTTP ni WS por ahora.

## Relacion con otros modulos
- seguimiento: tomaria eventos de seguimiento para calcular metricas.
- instancias: analizaria tiempos y estados por tramite.
- politicas: compararia comportamiento entre politicas activas.
